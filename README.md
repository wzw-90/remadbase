# База знаний «Безумие» (Remad.me)

Офлайн и онлайн база знаний по игре «Безумие» (Remad.me).

🌐 **Сайт онлайн:** [https://wzw-90.github.io/remadbase/](https://wzw-90.github.io/remadbase/)

### Разделы базы знаний:
- 🏥 **Корпуса и этажи**: интерактивный справочник по всем корпусам, этажам и дежурствам, наградам и требованиям.
- 🗡️ **Арсенал оружия**: 100 видов оружия с полными характеристиками урона, прокачкой, ценами и шансами улучшения.
- 📦 **Склад инвентаря**:
  - **Заначки (61)**: наглядная схема сбора коллекций, реальные боевые эффекты баффов, привязка элементов к этажам и боссам.
  - **Ивентовые предметы (92)**.
- 💀 **Досье боссов**: здоровье, урон, время боя, требования и подробные шансы дропа с интерактивными ссылками на оружие и заначки.
